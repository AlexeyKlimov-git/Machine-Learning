# Локальный агент для бэктестов

## Запуск

Нужны Python 3.11+ и установленный Ollama. В этой папке:

```bash
ollama pull qwen3.5:9b
python3 -m src.agent "Сравни buy-and-hold и скользящую среднюю на демо-данных"
```

Модель предложит план и сохранит его в `artifacts/agent/<id>/plan.json`.
Чтобы сразу выполнить план и получить объяснение результата:

```bash
python3 -m src.agent "Сравни buy-and-hold и скользящую среднюю на демо-данных" --execute
```

Если Ollama не запущен: `brew services start ollama`.

Для своих локальных бэктестов укажите в запросе путь к конфигу,
период с часовым поясом, snapshot и каталог кэша. Сначала получите план:

```bash
python3 -m src.agent "Прогони конфиг /путь/config.json с 2024-01-01T00:00:00Z до 2024-02-01T00:00:00Z, snapshot s1, cache /путь/cache" --allow-local-tools
```

Проверьте созданный `plan.json`, затем запустите именно этот план.
`local-binaries.json` должен содержать абсолютный путь к используемому инструменту,
например `{"backtest":"/путь/к/backtest"}`:

```bash
python3 -m src.agent "Прогони конфиг" --plan artifacts/agent/<id>/plan.json --execute --allow-local-tools --binaries local-binaries.json
```

## Результат

При полном запуске агент вызывает локальную LLM дважды: для плана и для
объяснения результата.
План проверяется перед выполнением. Выходные файлы: `plan.json`,
`run/summary.json`, результаты шагов и `report.md` в `artifacts/agent/<id>/`.

Проверенный запуск Qwen3.5 9B на искусственных ценах: модель выбрала окно 10,
runner выполнил его и передал результат модели для короткого отчёта.

| Стратегия | Доходность | Максимальная просадка |
|---|---:|---:|
| Buy-and-hold | −3.52% | 13.69% |
| Скользящая средняя, окно 10 | −11.16% | 15.39% |

Отдельно измерена работа runner без LLM:

| Измерение | Значение |
|---|---:|
| Медиана прямого запуска | 33.61 мс |
| Медиана через runner | 34.97 мс |
| Совпадение результатов | 5 из 5 |

Экономия времени от LLM пока не измерена. Реальные торговые данные в этом
эксперименте не использовались.
