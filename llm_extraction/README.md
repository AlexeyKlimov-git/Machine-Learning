# Извлечение полей из обращений

## Запуск

Python 3.11–3.13, команды из папки проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m src.evaluate --backend rules --output artifacts/rules
python -m src.evaluate --backend qwen --mode zero --output artifacts/qwen_zero
python -m src.evaluate --backend qwen --mode few --output artifacts/qwen_few
```

Первый запуск Qwen скачает около 1.2 ГБ весов. Модель работает локально.
Для повторной оценки используйте новые выходные папки.

## Результат

На выходе — JSON с полями `product`, `amount`, `category`.
Предсказания и метрики сохраняются в `artifacts/<run>/`.

Qwen3-0.6B, 16 искусственных тестовых обращений и 4 отдельных примера
для few-shot. Это небольшая проверка, не оценка на реальных банковских данных.

| Подход | F1 по полям | Валидный ответ | Полностью верная запись | Ложное заполнение |
|---|---:|---:|---:|---:|
| Правила | 0.9000 | 100% | 68.75% | 0% |
| Qwen без примеров | 0.4528 | 62.5% | 18.75% | 6.67% |
| Qwen с примерами | 0.9429 | 100% | 87.5% | 26.67% |

F1 считается по точным совпадениям непустых полей.
Ложное заполнение — доля заполненных полей там, где должен быть null.

Медианная задержка Qwen: 0.660 с без примеров и 0.636 с с примерами.
CPU, macOS ARM64, batch=1, после прогрева, без загрузки весов.

С примерами модель чаще возвращает правильный ответ, но иногда выдумывает
отсутствующие данные. Валидный JSON не гарантирует правильность содержимого.
