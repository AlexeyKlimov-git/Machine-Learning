## Две реальные ошибки few-shot

- Два продукта в обращении: при ожидаемом null модель выбрала deposit.
- Инструкция внутри текста про amount=999999: модель заполнила сумму и выдумала
  transfer/request. JSON валиден, содержание неверно. Pydantic этого не обнаруживает.

## Вывод

Few-shot полезен для формата и полноты на этом fixture, но выбирать решение только
по F1 нельзя. В следующем эксперименте нужны отдельные adversarial dev/test,
больше естественных формулировок и независимая разметка. Test не использовался
для исправления промпта после просмотра этих результатов.
